# План: радиоуправление черепахами (шаг 1 дорожной карты)

Цель: с компьютера **#1** командовать черепахами по радио. Никаких глушилок,
снифферов и подделок — только честное управление. Единственный «защитный» код —
подпись сообщений, и она помогает нам, а не атакующему.

Правило CHRONARCH: ни одна программа не уходит в игру, пока не прошла тесты в
эмуляторе. Поэтому сначала код (Часть A, делаю я), потом настройка в игре
(Часть B, делаешь ты по моим командам).

## Часть A — код (делаю я на Маке) — ✅ ГОТОВО

- [x] **A1. Эмулятор сети** — `tests/net.lua`: несколько компьютеров на
  настоящих `rednet`/`parallel`, очередь событий, таймеры, модемы, общий эфир.
- [x] **A2. Тесты** — `tests/test_protocol.py` (14) и `tests/test_net.py` (6):
  `ping`/`mine`, приём статусов и логов, подпись/проверка.
- [x] **A3. Доведены** `agent.lua` и `base.lua` — работают через подписанный
  протокол.
- [x] **A4. Подпись** — `common/chronarch.lua`: HMAC-SHA256 на общем секрете.
  Черепаха и база молча выбрасывают всё без верной подписи. Проверено тестом:
  поддельный приказ и фальшивый статус отлетают.
  _ponytail-потолок: подпись закрывает подделку, но не повтор (replay). Хватит,
  чтобы чужой компьютер не командовал черепахами. Понадобится серьёзнее —
  заменим._

Итог: 63 теста зелёные (`sh tests/run_all.sh`). Файлы готовы к игре:
`common/chronarch.lua`, `turtle/agent.lua`, `base/base.lua`.

## Часть B — настройка в игре (делаешь ты)

Режимы: `>` — оболочка (`ls`, `label`, `mine`), `lua>` — код. Не путай.
Весь вывод на экран в программах — латиницей (шрифт CC не показывает кириллицу).

### B1. Компьютер #1 (база)
1. В режиме `>` залей базу:
   ```
   pastebin get <КОД> startup.lua
   ```
2. Дай ему имя, чтобы не терял файлы при поломке:
   ```
   label set base1
   ```
3. Перезагрузка:
   ```
   reboot
   ```
   После загрузки сам запустится экран базы со строкой ввода.

### B2. Черепаха xhoxi
1. Проверь, что на ней стоят **кирка** и **эндер-модем** (оба слота заняты) и
   внутри есть уголь на топливо.
2. В режиме `>`:
   ```
   pastebin get <КОД_AGENT> startup.lua
   label set xhoxi
   reboot
   ```

### B3. Ещё черепахи (по желанию, 1–2 для начала)
То же, что B2, но каждой — своё имя: `label set xhoxi2` и т. д.
У каждой свой модем и своя кирка.

### B4. Секрет (только если берём A4)
Я дам одну команду, которая кладёт один и тот же секрет на базу и на каждую
черепаху. На одиночном мире это безопасно — файлы лежат только на твоём Маке.
_(На сервере ютубера секрет хранится иначе — разберём, когда дойдём туда.)_

### B5. Проверка
На базе в строке ввода:
```
list
```
— должна появиться `xhoxi`.
```
mine xhoxi 8
```
— черепаха копает 8 блоков, а в логе базы идут её статусы.

## Чего в этом плане НЕТ (специально)
- глушилок и флуда;
- снифферов чужого эфира;
- подделки чужих сигналов.

Подпись из A4 — это замок на нашу дверь, а не отмычка к чужой. Атакующему она
ничем не помогает.
