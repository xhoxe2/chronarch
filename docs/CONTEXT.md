# Предыстория и решения

Сжатый пересказ первого разговора (ноябрь 2026), из которого вырос проект.

## Сервер и сборка Ascension of Ages
- Автор WellRareSteak, сборка на CurseForge: https://www.curseforge.com/minecraft/modpacks/ascension-of-ages
- Публичный репозиторий: https://github.com/andrewgodowsky-aoa/ascension-of-ages-public (там issues с найденными багами)
- v0.7.4.0: NeoForge 21.1.248, Minecraft 1.21.1, 594 мода, рекомендуемая RAM 10 ГБ.
- 8 эпох (стадии AStages): `dark_ages` → `medieval_times` → `the_renaissance` → `industrial_revolution` → `gilded_age` → `atomic` → `otherworldly` → `ascension`.
- Гейтинг предметов по эпохам задаётся в `overrides/kubejs/server_scripts/aoa_astages_*.js` (тысячи записей вида `["gilded_age", "pneumaticcraft:programmer", "block_item"]`).
- Свой мод автора AoA Core управляет прогрессом на сервере, поэтому со стороны клиента его не обойти.
- Автор сам делает сборку с Claude и Codex: в `kubejs/` лежат `CLAUDE.md` и `AGENTS.md`.
- **CC: Tweaked и Advanced Peripherals в сборке нет.**
- Что в ней есть полезного:
  - **PneumaticCraft: Repressurized**: программируемые дроны. В Programmer есть импорт и экспорт программ в JSON (буфер обмена, Pastebin), то есть ИИ может писать программы дронам. Programmer и Programmable Controller открываются в эпохе `gilded_age` (5-я). Пульт Remote тоже экспортируется в JSON.
  - **Create**: Schematicannon строит по чертежам `.nbt`. Лимит сервера 256 КБ на чертёж (`create-server.toml`, `maxTotalSchematicSize`). Механизмы открываются в 2–3-й эпохах.
  - **Integrated Dynamics** (с 4-й эпохи): внутриигровая логика, но программы туда извне не вставить.
  - AE2, Refined Storage, Mekanism, MineColonies (кастомные чертежи игроков на сервере выключены: `allowPlayerSchematics = false`).

## Что пользователю нравится и что нет
- Нравится: ИИ, который **сам открывает новое**: колония, которая эволюционирует; Око, которое находит то, чего не видел даже автор сборки.
- Не понравилось (не предлагать снова): ИИ-помощник, автомонтаж видео («Шоураннер»), бот-игрок с отдельным аккаунтом («Воплощение»), простые уведомления.
- Хочет, чтобы проект выглядел сложным и гениальным, и им можно было похвастаться перед ютубером.

## Ключевые идеи
- **Генезис / Колония**: черепахи учатся навыкам (ИИ пишет код, черепаха пробует, ошибки исправляются), навыки складываются в библиотеку. Версии кода соревнуются по эффективности, лучшие «размножаются» с мутациями. Новые черепахи наследуют навыки, есть родословная. Сайт «Мозг» с картой колонии, древом поколений и графиками эволюции.
- **Око**: граф всех рецептов и гейтинга сборки, детекторы аномалий (дыры в гейтинге, недостижимые квесты), ИИ пишет отчёты о багах. Найденные дыры **не использовать** на сервере, а отправлять автору.
- **Кузня**: на локальной копии сборки ИИ подбирает Create-фабрики, гоняет их на испытательном стенде, лучшие чертежи строятся на сервере через Schematicannon.
- **Реалистичная роль ИИ**: бесплатные модели собирают и пересказывают, Claude Code думает и пишет код, пользователь решает. Автономность наращивается постепенно (позже Claude Code можно запускать по расписанию).

## Уроки CC, которые уже пройдены
- Режимы `>` и `lua>`; `id`, `label set`, `ls`, `edit`, `peripherals`, `pastebin get`, `wget`.
- Монитор вплотную к компьютеру: `monitor back hello`, `monitor scale <сторона> <n>`.
- `peripheral.call("right", "getLabel")` читает имя соседней черепахи. Соседство даёт только включить, выключить или перезагрузить.
- Эндер-модемы: на компьютер ставится через Shift + ПКМ, в черепаху — в слот улучшения в её окне. `peripheral.find("modem", rednet.open)`, `rednet.send(id, msg)`, `rednet.receive()` → `id, msg, protocol`.
