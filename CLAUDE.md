# CHRONARCH

Система ИИ для Minecraft на компьютерах и черепахах CC: Tweaked. Название значит «Властитель эпох» (chronos + archon).
Подробная предыстория, все идеи и решения: `docs/CONTEXT.md`.

## Как работать с пользователем
- Отвечай **по-русски**, простыми словами. Пользователь только начал изучать CC: Tweaked и Lua.
- Объясняй по шагам и давай точные команды для игры. Всегда уточняй режим: `>` (оболочка: `ls`, `mine 16`) или `lua>` (код). Он уже путал их.
- В программах всё, что выводится на экран в игре, пиши **латиницей**: шрифт CC не показывает кириллицу.
- Пользователь присылает скриншоты игры, это главный источник правды о том, что происходит.

## Цель
CHRONARCH = **Око** (знание сборки: рецепты, эпохи) + **Колония** (черепахи, которые учатся и улучшаются) + **Кузня** (машины Create).
Задача: сделать то, чем можно удивить ютубера, на сервере которого играет пользователь, и до чего другие не додумались.

Главный принцип: **рутину делают скрипты** (0 токенов), **ИИ только решает или отвечает**. Тяжёлые улучшения кода делает Claude Code циклами: собрать данные в игре → кратко проанализировать дешёвой моделью → улучшить код → прогнать тесты → выкатить.

## Где играем
- **Тренировка:** All the Mods 10 (Minecraft 1.21.1, NeoForge), одиночный мир, творческий режим, Мак.
  Есть CC: Tweaked (CraftOS 1.9) и Advanced Peripherals (Chunk Controller, Geo Scanner, Chat Box, Environment Detector, Automata Cores).
  HTTP у игровых компьютеров работает (`wget`, `pastebin get` проверены).
- **Основной сервер ютубера:** сборка Ascension of Ages v0.7.4.0 (NeoForge 1.21.1, 594 мода). **CC: Tweaked там НЕТ.** Подробности в `docs/CONTEXT.md`.
- **Жёсткие правила:** сервер и моды не менять. Никаких ботов, макросов, автокликеров и читов, иначе бан. Не нагружать сервер: 3–8 черепах, спокойный ритм.

## Что уже есть в мире ATM10
- Компьютер **#1**: Advanced Computer под продвинутым монитором (`monitor <сторона> hello` работал), с эндер-модемом.
- Черепаха **#0**, label **`xhoxi`**: Advanced Turtle с киркой и эндер-модемом, внутри блоки угля.
- `mine.lua` на черепахе работает (прокопала шахту). Ставили через Pastebin.
- Радио проверено: `rednet.send(0, "hello xhoxi")` с компьютера → `rednet.receive()` на черепахе получила.

Протокол rednet `"chronarch"`: база → черепаха `{cmd="ping"|"mine"|"scan"|"dig"|"mineArea"|"stop", ...}` (у `mine` — `length,depth`; у `scan` — `radius`; у `dig`/`mineArea` — `radius` и опц. `cx,cy,cz` для центра/клика). Черепаха → база `{type="status"|"log"|"done"|"scan"|"dig"|"harvest", name, ...}`: `scan` несёт сводку руды, `harvest` — живую карту (позиция `@`, оставшаяся руда). Все сообщения подписаны HMAC-SHA256 на общем секрете (`/chronarch.key`); сообщение без верной подписи молча отбрасывается. Подпись закрывает подделку, но не повтор (replay) — см. комментарий в `chronarch.lua`.

## Тесты (обязательно)
```bash
python3 -m venv .venv && .venv/bin/pip install lupa   # один раз (Homebrew-питон не даёт ставить глобально)
sh tests/fetch_ccrom.sh                                # один раз: настоящие модули CC
sh tests/run_all.sh                                    # все наборы: mine, probe, protocol, status, orescan, oremap, navigate, net
```
Отдельный набор: `.venv/bin/python tests/test_net.py`. Тесты запускаются на Lua 5.5 (lupa); игровой код не использует синтаксис новее 5.2 и берёт `bit32` из шима в тестах.

**Правило: ни одна программа не уходит пользователю, пока не прошла тесты в эмуляторе.** Для каждой новой программы сначала дописываем модель мира и тесты.

Быстрая проверка синтаксиса: `brew install lua`, потом `luac -p turtle/mine.lua`.

## Разведчик: факты из игры вместо памяти
`tools/probe.lua` ничего не двигает и не ломает (черепаха только поворачивается на месте; `probe noturn` — без поворотов). Он записывает:
- точные версии (`_HOST`, CraftOS, Lua) и все функции всех API этой версии CC;
- все подключённые устройства: типы, **полный список методов**, значения безопасных геттеров (`size`, `list`, `getSize`, `isWireless`…). Остальные методы только перечисляются и никогда не вызываются;
- точные id и теги предметов в сундуках и в инвентаре черепахи;
- блоки вокруг черепахи с тегами, топливо, улучшения.

**Правило:** прежде чем писать код под новое устройство, мод или блок, попроси пользователя поставить его рядом и запустить `probe`, затем прочитай отчёт.
- **Одиночный мир:** отчёт лежит в папке компьютера в `saves/<мир>/computercraft/computer/<id>/probe-<id>.json`, читай его прямо оттуда.
- **Сервер:** пользователь вводит в игре `pastebin put probe-<id>.json` и присылает код. Скачай `https://pastebin.com/raw/<код>`. Вставка публичная, в отчёте нет координат и секретов.

## Как код попадает в игру
- **Сейчас:** вставка на pastebin.com, в игре `pastebin get <код> <файл>`. Ctrl+V в CC вставляет только **одну строку**, поэтому вставлять код вручную нельзя.
- **Одиночный мир:** файлы игровых компьютеров лежат прямо на Маке: `~/Documents/curseforge/minecraft/Instances/All the Mods 10/saves/<мир>/computercraft/computer/<id>/` (путь проверить). Туда можно класть программы напрямую.
- **Сервер:** файлы компьютеров лежат на сервере, напрямую писать нельзя. План: публичный GitHub-репозиторий и программа `update.lua` в игре, которая скачивает свежие версии по raw-ссылкам.

## Ограничения CC, которые важно помнить
- Черепаха работает только в загруженных чанках. Решение — Chunky Turtle (Chunk Controller из Advanced Peripherals).
- У черепахи два слота улучшений. Менять их на ходу: `turtle.equipLeft()` / `turtle.equipRight()`.
- Периферия подключается только вплотную (или через проводной модем и кабель). `peripherals` показывает соседей.
- Компьютер или черепаха без `label` теряет файлы при поломке.
- Топливо: уголь = 80 ходов, блок угля = 800. Угольная руда — не топливо.

## ИИ и деньги
- Claude Code (Opus) — главный мозг: пишет и улучшает код.
- Дешёвые или бесплатные модели для анализа логов и решений в игре: Gemini Flash (бесплатный тариф), Groq (`gpt-oss-120b`, бесплатно 1000 запросов в день), decision-модели Jev (TypeSafe, $0.042 за 1M входных токенов, ответ бесплатно) или `pplx-decider-flash` ($0.01 за 1M). Лестница: decision-модель → Gemini/Groq → Claude Code.
- **Ключи API никогда не кладём в игровые компьютеры** (на сервере их может прочитать владелец). Ключи живут только в «Мосте»: Cloudflare Worker, бесплатно 100k запросов в день, D1 для памяти.
- Локальную модель на ноуте во время игры не запускаем: падает FPS.
