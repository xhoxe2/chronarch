# CHRONARCH

Система ИИ для Minecraft на компьютерах и черепахах **CC: Tweaked**.
«Властитель эпох» (chronos + archon): Око (знание сборки) + Колония (черепахи,
которые учатся) + Кузня (машины Create).

Подробности и дорожная карта — в [`CLAUDE.md`](CLAUDE.md), предыстория — в
[`docs/CONTEXT.md`](docs/CONTEXT.md).

## Что умеет сейчас

- Подписанное (HMAC-SHA256) радиоуправление черепахами с базы.
- Монитор базы: живая таблица статуса всех черепах.
- Geo Scanner: `scan` — сводка руды вокруг; `harvest` — выгрести всю руду
  области; живая карта руды на мониторе (клик по руде → копать её); `stop` —
  отзыв домой.

## Куда что кладётся в игре

| Компьютер | Файлы |
|---|---|
| Черепаха | `chronarch.lua`, `navigate.lua`, `orescan.lua`, `mine.lua`, `update.lua`, `agent.lua` → `startup.lua` |
| База | `chronarch.lua`, `statusview.lua`, `oremap.lua`, `update.lua`, `base.lua` → `startup.lua` |

У обоих один общий секрет `/chronarch.key` (его в репозитории **нет** и быть не
должно).

## Обновление кода в игре

В игре на компьютере или черепахе:

```
update
```

`update.lua` сам определяет роль (черепаха или база), качает свежие файлы из
этого репозитория по raw-ссылкам и перезаписывает их. Секрет `chronarch.key` не
трогает. После обновления — перезагрузка (зажать `Ctrl+R`).
