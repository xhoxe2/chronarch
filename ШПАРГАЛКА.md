# CHRONARCH — шпаргалка: что где и что вводить

## Три уровня

1. **Машина** — черепаха, компьютер базы, карманный компьютер, GPS-компьютер.
2. **Программа** — на каждой машине **одна**. Она говорит, что машина делает.
3. **Команды** — то, что вводишь внутри программы.

## Машины и программы

| Машина | Имя (label) | Программа | Как запускается | Что ты вводишь |
|---|---|---|---|---|
| Черепаха | `xhoxi` | `mining` | сама при включении | ничего: приказы ей шлют база и карманный |
| Компьютер + монитор | `base` | `control` | сам при включении | в строке `base>`: `harvest`, `map`, `ask`… (можно поставить и на карманный: `cx install control`) |
| Карманный компьютер | `pda` | `buddy` | `cx buddy` (или `cx colony`) | в строке `buddy>`: `come here`, `follow`… |
| Компьютер на летающем аппарате | `pilot` | `pilot` | **`pilot calibrate`** — анализ судна (на ногах): все приборы, проверка двигателей, учебный подъём ~40 с (руки не трогать, сам сядет), отчёт «что доступно и почему нет». **`pilot`** — полёт. `pilot info` — отчёт ещё раз | `W/S/A/D` лететь, `Пробел/Shift` вверх/вниз, `L` посадка, **любая другая клавиша — двигатели off** |
| GPS-башня (4 шт.) | `gps1`…`gps4` | `gps` | сама при включении | ничего |

## Где ты сейчас вводишь — смотри на начало строки

| Видишь | Ты в… | Туда вводится |
|---|---|---|
| `>` | оболочке CraftOS | `cx …`, `ls`, `edit` |
| `lua>` | режиме кода Lua | код (`exit()` — выйти) |
| `base>` | программе базы | `help`, `list`, `harvest xhoxi 16 diamond`… |
| `buddy>` | помощнике на карманном | `come here`, `follow`, `home`… |

## Команда `cx` — на любой машине, в оболочке `>`

| Ввод | Что будет |
|---|---|
| `cx` | где я: машина, программа, как она запускается |
| `cx help` | команды программы этой машины |
| `cx list` | все наши программы (то же самое: `programs-custom`) |
| `cx update` | скачать свежий код (потом зажать `Ctrl+R`) |
| `cx install mining` | поставить другую программу |
| `cx install gps 645 63 -107` | сделать компьютер GPS-хостом (координаты с F3) |
| `cx buddy` | запустить помощника (на карманном) |

Старые команды `update`, `program`, `programs-custom` тоже работают.

## База (`base>`)

| Команда | Что делает |
|---|---|
| `help` | все команды |
| `list` | кто онлайн |
| `harvest xhoxi 16 diamond` | найти руду в радиусе, выкопать, домой (сама спустится на глубину руды) |
| `explore xhoxi 24` | прочесать всю область и выкопать всё |
| `swarm 32 diamond` | все свободные черепахи делят область и копают вместе |
| `scan xhoxi 8` | сводка руды вокруг |
| `map xhoxi` / `status` | на мониторе карта руды / список черепах |
| `stop xhoxi` | бросить работу и домой |
| `ask <вопрос>` | спросить ИИ (по-английски); `yes` — выполнить его план |
| `value diamond 10` | ценность руды (самая ценная копается первой) |
| `sety xhoxi 63` | высота дома без GPS |
| `forget xhoxi` | стереть память карты черепахи |

## Помощник (`buddy>` на карманном)

| Команда | Что делает |
|---|---|
| `come here` | черепаха бежит к тебе |
| `follow` / `stay` | ходит за тобой / стоп на месте |
| `home` | домой к сундуку, разгрузиться |
| `stash` | выгрузить добычу в ender-сундук прямо на месте |
| `dig here 8` | выкопать руду вокруг тебя |
| `light` | поставить факел |

Имя черепахи можно не писать, пока она одна. Выйти: `Ctrl+T`.

## Что положить черепахе

Кирка и эндер-модем — надеты. В инвентаре: **Geo Scanner**, **ведро** (пьёт
лаву), **уголь**, **Chunk Controller** (не выгружается, когда ты далеко),
по желанию **EnderStorage-сундук** (разгрузка на месте) и **факелы**.

## Если что-то не так

- На мониторе **красный `SOS …`** — черепаха просит помощи (кончилось топливо,
  застряла, потеряла сундук). База сама спросит ИИ, что делать.
- Поменял код — **`Ctrl+R`** на машине, иначе работает старый.
- Не знаешь, где ты, — введи **`cx`**.

## Код в репозитории лежит так же

| Папка | Что там |
|---|---|
| `programs/mining/` | программа черепахи (`startup.lua`, `mine.lua`) |
| `programs/control/` | программа базы |
| `programs/buddy/` | помощник и колония для карманного |
| `programs/gps/` | хост GPS-башни |
| `lib/` | общие библиотеки (в игре папка `/lib`) |
| `tools/` | разовые утилиты: `probe`, `gpssetup` |
| `bridge/` | Мост к ИИ (Cloudflare) |
| `tests/` | тесты |
